# ADR-0004：将上游缺陷调查纳入学习成果

日期：2026-10-07。状态：accepted。依据：P-008。

## 决定

建立缺陷台账、记录模板和独立复现目录约定。分类与处理状态分开，保留精确版本、官方依据、合成最小复现、影响、规避、上游状态和升级回归。

未经用户明确授权不公开发送 Issue、评论或 PR。疑似缺陷不称为上游确认；使用错误也可以形成有价值的学习章节。

## 取舍与复查

只保存聊天或零散注释易丢失复现条件；为每个安装错误创建上游 Issue 又会给维护者制造负担。当前流程在本地先完成证据和分类，再决定是否反馈。

不预先填充示例 bug、不按数量考核。升级依赖时检查相关 workaround 和已登记缺陷，在验证修复后清理，避免长期遗留不可解释补丁。
