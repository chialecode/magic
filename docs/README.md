# Magic 文档导航

Magic 是一个长期演进的多技术栈二次元社区学习项目。文档与工程规则已经开始建立，业务服务与客户端均待实现。已确认要求、设计建议与实际执行结果分别维护。

## 阅读路径

- 了解产品：[项目原则](product/principles.md) → [需求基线](requirements.md) → [路线与验收](delivery/roadmap-and-acceptance.md)。
- 开始开发：[工作入口](../AGENTS.md) → [执行状态](delivery/status.md) → [当前阶段计划](delivery/stage-plan.md) → 对应技术正本。
- 理解架构：[总体架构](design/architecture.md) → [领域与数据](design/domain-model.md) → [API 与事件](design/api-and-events.md) → [部署设计](design/deployment.md)。
- 学习技术：[学习手册](learning/README.md)，按问题、方案比较、实际应用和验证实验阅读。
- 处理开源缺陷：[缺陷流程](dev-rules/upstream-bugs.md) → [台账](upstream/README.md) → [记录模板](templates/upstream-bug.md)。
- 修改规则：[文档治理](governance/documentation-policy.md) → [登记表](governance/document-registry.json) → [决策记录](decisions/README.md)。
