# 当前阶段计划

阶段：M0，文档与架构基础。分支：`docs/m0-foundation`。基点：只含空 README 的初始化提交。

GitHub：[M0 · 文档与架构基础](https://github.com/chialecode/magic/milestone/1)。本地交付完成后，远端集成与关闭里程碑按实际验证推进。

## 范围

1. 保留已确认需求，修订 M0 范围；整理文档正本、导航、登记和状态。
2. 完成总体架构、技术栈、服务边界、领域数据、API／事件、客户端和部署设计。
3. 建立书籍式学习手册，解释选型、替代方案、实验方法与未来实现入口。
4. 建立上游缺陷发现、最小复现、分类、规避、反馈授权与升级回归机制。
5. 建立开发规范、Git 单阶段提交规则、评审、质量检查、贡献入口及 GitHub 模板。
6. 接通本地文档门禁和对应 CI 配置；设置空仓库可用的远端基础保护，准备正式 PR／CI 保护。
7. 自审、验证并保存唯一 M0 提交；集中请求首次 push 与 PR 授权。

## 退出条件

本地文档和工程交付满足 [M0 验收](roadmap-and-acceptance.md)，检查通过并有报告。远端 CI、PR、GitBook 发布、产品运行与部署验收分别记录，缺少授权不冒充通过。

不在本阶段创建业务服务骨架、Docker Compose 样例应用或四种语言的空项目。实际部署入口移至后续工程实现，避免占位工程被误认为可用系统。
